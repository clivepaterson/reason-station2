              Tutorial 01 · Subtractor

              Creating a kick drum

              How to create a kick drum using Subtractor.

              To create a kick drum on any synthesizer, all you need is a sine wave set to the root note of the kick drum and white noise for the initial part of the sound.

              The Subtractor settings

              1. Create a Subtractor synthesizer and reset the device.
              2. Set Oscillator 1 to a sine wave on octave 4.
              3. Set Filter 1 to low-pass with the frequency at about 50%.
              4. Set the Mod Envelope to Oscillator 1 pitch with a decay value of 32. This starts the sine wave at a high pitch and quickly lowers it to the root note of the kick drum. This pitch drop is the essence of creating a kick drum on any synthesizer.
              5. There should be no need for a Filter Envelope.
              6. Set the Amp Envelope to no attack, a short decay and no sustain or release. You can adjust the decay values to suit the track, but leaving it too long will interfere with the bass elements of your track.
              7. Turn on the Noise Oscillator and adjust its decay, color, and level to suit the sound. A short decay is usually better.

              The effects

              Distortion

              Distortion often works well on a kick drum. I've chosen Scream 4 to give the kick some punch.

              Compression

              Compression is also useful for kick drums and helps give them more punch.

              Tutorial 02 · Subtractor

              Creating a hi-hat

              How to create a hi-hat using Subtractor.

              A hi-hat can be created using only the Noise Oscillator.

              The Subtractor settings

              1. Create a Subtractor synthesizer and reset the device.
              2. Turn off Oscillators 1 and 2.
              3. Turn on the Noise Generator and set its level and decay to maximum.
              4. Set Filter 1 to high-pass at around 7 kHz to remove all low frequencies.
              5. Set the Filter and Amp Envelopes to no attack, a very short decay, and no sustain or release.

              Tutorial 03 · Subtractor

              Creating an open hi-hat

              How to create an open hi-hat using Subtractor.

              A hi-hat can be created using only the Noise Oscillator. An open hi-hat uses the same technique as a closed hi-hat, but with a longer decay.

              The Subtractor settings

              1. Create a Subtractor synthesizer and reset the device.
              2. Turn off Oscillators 1 and 2.
              3. Turn on the Noise Generator and set its level and decay to maximum.
              4. Set Filter 1 to high-pass at around 6 kHz to remove all low frequencies. This is slightly lower than the frequency used for a closed hi-hat.
              5. Set the Amp Envelope to no attack, a short decay that is longer than the closed hi-hat, and no sustain or release.

              The effects

              Distortion

              Add some distortion to give the open hi-hat extra character.

              Tutorial 04 · Subtractor

              Creating a snare drum

              How to create a snare using Subtractor.

              A snare drum is similar to a kick drum, but uses a band-pass filter to occupy a tighter mid-frequency space.

              Before you begin: create a Line Mixer so that you can combine two Subtractor synthesizers.

              Subtractor 1: triangle or sine wave

              1. Create a Subtractor synthesizer and reset the device.
              2. Set Oscillator 1 to a triangle or sine wave. A triangle wave adds more harmonics to the sound.
              3. Set Filter 1 to band-pass. This excludes low frequencies so the snare can occupy a tight frequency space. Adjust the filter frequency to suit the note you are playing.
              4. Use no Filter Envelope.
              5. Set the Mod Envelope to Oscillator 1 pitch with a decay value of 20, so the sound starts at a high pitch and quickly lowers to the root note.

              Subtractor 2: noise

              1. Create another Subtractor synthesizer for white noise and reset the device. This lets you control the white noise ADSR independently.
              2. Turn off Oscillators 1 and 2 by disabling Oscillator 2 and moving the mix fully toward Oscillator 2.
              3. Turn on the Noise Generator and set decay and level to 100%. Adjust the color to taste.
              4. Set the Amp Envelope to no attack, a very short decay, and no sustain or release.
              5. Reduce the volume of the white-noise Subtractor until it mixes well with Subtractor 1's triangle sound.

              The effects

              Compression

              Add a compressor and increase the ratio to boost the sound. Wire both Subtractors to the Line Mixer, then connect the Line Mixer to the compressor.

              Distortion

              Add distortion to give the snare more crunch. This example uses Scream 4 tube distortion.
