Creating a basic super saw

How to create a basic super saw using Subtractor.

The Roland JP-8000 synthesizer introduced the first supersaw sound, allowing multiple oscillators to play from a single keystroke. A super saw layers several sawtooth oscillators, detunes them slightly from one another, and produces the rich sound that has become synonymous with trance music and man other genres. We are going to recreate that idea with eight oscillators across four Reason Subtractors.

The Combinator setup

  1. Create a Combinator to contain all of the devices that make up the sound.
  2. Add a Line Mixer 14:2. We will use it to mix four Subtractors.
  3. Add four Subtractors, reset each one to its initial patch, and connect their audio outputs to Line Mixer channels 1–4.

The Subtractor settings

  1. Use a sawtooth wave for Oscillators 1 and 2 on all four Subtractors.
  2. Set the Filter Envelope Velocity control to 0 on every Subtractor so key velocity does not affect the filter.
  3. Set Amp Envelope Sustain to 127 (100%) on every Subtractor.
  4. Turn on Oscillator 2 on every Subtractor. You now have eight sawtooth oscillators playing for each MIDI note.
  5. Use the Cent controls to detune the eight oscillators in four-cent steps: −14, −10, −6, −2, +2, +6, +10, and +14 cents.

The effects

RV-7 reverb

Add an RV-7 Digital Reverb, reduce its Size setting, and connect it to a Send and Return pair on the Line Mixer 14:2. Use the channel send controls to blend reverb into the four Subtractors.

The Combinator settings

Note: Click the Editor button on the Combinator to access these settings.

  1. Select each Subtractor in turn and map Filter Frequency, Filter Resonance, and Amp Release to Combinator Rotary Controls 1, 2, and 3. Set each mapping range from 0 to 127.
  2. Select the Line Mixer and map Combinator Rotary Control 4 to the Channel 1–4 Aux 1 Send controls. Set each mapping range from 0 to 127 so one control adjusts the reverb level for all four Subtractors.
  3. Play the sound while adjusting the four rotary controls from your MIDI keyboard to shape the filter, release, and reverb.
