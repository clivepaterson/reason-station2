Creating a kick drum

How to create a kick drum using Subtractor.

To create a kick drum on any synthesizer, all you need is a sine wave set to the root note of the kick drum and white noise for the initial part of the sound.

The Subtractor settings

  1. Create a Subtractor synthesizer and reset the device.
  2. Set Oscillator 1 to a sine wave on octave 4.
  3. Set Filter 1 to low-pass with the frequency at about 50%.
  4. Set the Mod Envelope to Oscillator 1 pitch with a decay value of 32. This starts the sine wave at a high pitch and quickly lowers it to the root note of the kick drum. This pitch drop is the essence of creating a kick drum on any synthesizer.
  5. There should be no need for a Filter Envelope.
  6. Set the Amp Envelope to no attack, a short decay and no sustain or release. You can adjust the decay values to suit the track, but leaving it too long will interfere with the bass elements of your track.
  7. Turn on the Noise Oscillator and adjust its decay, color, and level to suit the sound. A short decay is usually better.

The effects

Distortion

Distortion often works well on a kick drum. I've chosen Scream 4 to give the kick some punch.

Compression

Compression is also useful for kick drums and helps give them more punch.
