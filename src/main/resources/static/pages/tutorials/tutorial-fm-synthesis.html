FM synthesis using Subtractor

How to do some basic FM synthesis using Subtractor and CV routing.

Frequency modulation (FM) changes the pitch of one signal, called the carrier, with another signal, called the modulator. Slow modulation makes the pitch wobble; faster modulation creates new harmonics and more complex tones. Subtractor has a built-in FM Amount control and a Ring Mod toggle, but in this beginner example we will use CV routing so you can see and hear the modulation sources separately.

For more detail on Subtractor's FM and ring modulation controls, see the Reason Studios documentation.

Subtractor 1: the sound synth

  1. Create a Subtractor and reset the device.
  2. Set Oscillator 1 to a sine wave.
  3. Open Filter 1 fully so all frequencies pass through.
  4. Set Amp Envelope Sustain to 127 (100%).
  5. Set the Filter Envelope Velocity control to 0 so key velocity does not alter the filter.

Subtractor 2: the envelope CV generator

  1. Create a second Subtractor. Make sure its Audio Output is not connected; this device is only generating a CV signal.
  2. On the Mod Envelope, set Attack to 0, Decay to about 61, and Sustain and Release to 0.
  3. Press Tab to turn the rack around. Connect Subtractor 2's Mod Env Modulation Output to Subtractor 1's OSC Pitch Modulation Input.
  4. Play some notes. You should hear the sine wave sweep from a high frequency down to a low frequency each time a note triggers the envelope.

Combine the CV signals with Spider CV

  1. Create a Spider CV Merger & Splitter.
  2. Disconnect Subtractor 2's Mod Env cable from Subtractor 1 and connect it to a Spider Merge input instead.
  3. Connect the Spider's merged CV output to Subtractor 1's OSC Pitch Modulation Input.

Thor: the sine-wave CV generator

  1. Create a Thor Polysonic Synthesizer. Make sure its Audio Output is not connected; Thor is only generating a sine-wave CV signal.
  2. Set Thor's LFO 2 waveform to sine, turn on Key Sync, turn off Tempo Sync, and set the rate to about 2.14 Hz.
  3. Press Tab to turn the rack around. Connect Thor's LFO 2 Modulation Output to another Spider Merge input.
  4. Set that Spider merge input to about 2.25 to reduce the CV signal strength.
  5. Play some notes. The pitch should wobble up and down with Thor's sine wave while Subtractor 2's Mod Envelope sweeps the pitch downward with each key trigger.
