The Oscillators

A description of the four basic oscillators: sine, square, triangle, and sawtooth, and how they are generated.

An oscillator creates a repeating waveform. The waveform determines which frequencies are present, while the oscillator frequency determines the note we hear. Sine waves are the building blocks: summing sine waves at whole-number multiples of a note's fundamental frequency creates the other basic waveforms.

The sine wave

  • This is the most basic oscillator. It is a single sine wave at the frequency of the note, also known as the fundamental frequency (f).
  • Each note on a keyboard has a frequency. For example: C2 is 65.41 Hz, C3 is 130.81 Hz, C4 (middle C) is 261.63 Hz, G4 is 392.00 Hz, and A4 is 440.00 Hz.
  • Sine wave harmonic recipe
    HarmonicFrequencyRelative amplitudePhase
    1stf10°

The square wave

  • A square wave is created by summing multiple sine waves. In fact, all of the basic oscillators in this tutorial can be created by adding sine waves together.
  • Add the odd harmonics of the fundamental frequency. The relative amplitude of each harmonic is the inverse of its harmonic number.
  • Square wave harmonic recipe
    HarmonicFrequencyRelative amplitudePhase
    1stf10°
    3rd3f1/30°
    5th5f1/50°
    7th7f1/70°
    9th9f1/90°

Building the square wave

The triangle wave

  • A triangle wave uses odd harmonics of the fundamental frequency.
  • Each harmonic's relative amplitude is the inverse square of its harmonic number. The phase alternates by 180 degrees, which means every second included harmonic is inverted.
  • Triangle wave harmonic recipe
    HarmonicFrequencyRelative amplitudePhase
    1stf10°
    3rd3f1/3²180°
    5th5f1/5²0°
    7th7f1/7²180°
    9th9f1/9²0°

Building the triangle wave

The sawtooth wave

  • A sawtooth wave is created by summing every harmonic of the fundamental frequency.
  • Each harmonic's relative amplitude is the inverse of its harmonic number. For the orientation shown here, the phase alternates by 180 degrees, so the even harmonics are inverted.
  • Sawtooth wave harmonic recipe
    HarmonicFrequencyRelative amplitudePhase
    1stf10°
    2nd2f1/2180°
    3rd3f1/30°
    4th4f1/4180°
    5th5f1/50°
    6th6f1/6180°
