Creating a hi-hat

How to create a hi-hat using Subtractor.

A hi-hat can be created using only the Noise Oscillator.

The Subtractor settings

  1. Create a Subtractor synthesizer and reset the device.
  2. Turn off Oscillators 1 and 2 by disabling Oscillator 2 and moving the mix fully toward Oscillator 2.
  3. Turn on the Noise Generator and set its level and decay to maximum.
  4. Set Filter 1 to high-pass at around 7 kHz to remove all low frequencies.
  5. Set the Filter and Amp Envelopes to no attack, a very short decay, and no sustain or release.
  6. Set the Velocity of the Amp to +57. This allows the velocity of the note to set the volume of the hi-hat.
