Creating a bass

How to create a bass sound using Subtractor.

There are many ways to make a bass sound. This is a very basic example.

The Subtractor settings

  1. Use a sawtooth wave for Oscillators 1 and 2. Set Oscillator 2 one octave lower, then mix the two oscillators equally.
  2. Set Filter 1 to low-pass.
  3. Set the Filter Envelope to no attack, a short decay, and no sustain or release.
  4. Set the Amp Envelope to no attack or decay, 100% sustain, and a short release.

The effects

Sidechain compression

Add an MClass Compressor for sidechaining. On the rear panel, split the kick drum signal and connect it to the compressor's Sidechain In. This ducks the bass volume each time the kick plays, helping the two sounds sit together in the mix.

Set a low threshold and a high ratio, then adjust them to suit your track.
