Tutorial 09 · Subtractor

A nice simple FM bell sound using Subtractor

How to make a basic FM bell sound using Subtractor.

We are going to use Subtractor's FM knob to make this sound. Oscillator 1 will be the sound you hear, while Oscillator 2 rapidly modulates its pitch to create the bell-like harmonics.

Subtractor settings

  1. Create a Subtractor synth and reset the device.
  2. Set Oscillator 1 to a sine wave and turn the oscillator mix fully toward Oscillator 1.
  3. Turn on Oscillator 2, set it to a sine wave, and raise it by one octave.
  4. Set the FM knob to about 43. Adjust it to your liking: Oscillator 2 is not heard directly at this mix setting, but it alters Oscillator 1's pitch at a very high rate.
  5. Open Filter 1 fully to let the whole sound through.
  6. Set the Amp Envelope to 0 attack, 50 decay, 0 sustain, and 60 release. This creates a nice plucked bell sound; adjust the release to your liking.

Effects

  1. Add a CF-101 Chorus/Flanger to give the sound an ambient, airy feel.
  2. Add an RV-7 Digital Reverb. Select the Medium Room algorithm, reduce the Size, and set Dry/Wet to about 36.
  3. Optional: Add a DDL-1 Digital Delay Line. Set Steps to 2 so the echoes land on the beat, and set Dry/Wet below 50% so the initial pluck remains the loudest part of the sound.
