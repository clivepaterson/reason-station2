Tutorial 06 · Subtractor

Creating a lead / pad with pulse width modulation (PWM)

How to create a basic lead using Subtractor with sawtooth pulse width modulation.

We are going to use Subtractor's PWM feature to create a rich lead sound.

The Subtractor settings

  1. Use a sawtooth wave for Oscillators 1 and 2. Detune Oscillator 2 by -3 cents, then mix the two oscillators equally.
  2. Set the phase mode to subtraction (−). This subtracts a phase-offset copy of each sawtooth, producing a square wave whose pulse width can be controlled with the Phase knob.
  3. Set LFO 1 to a triangle wave, route it to Phase, and use a rate of about 36 and an amount of 127. This continuously varies the pulse width of the square wave.
  4. Set LFO 2 to a phase wave and a rate of 64 and an amount of 127.
  5. Set the filter's Velocity control to 0 so note velocity does not alter the filter.
  6. Set Filter 1 to high-pass to remove the low frequencies. We will add a low-pass filter later in the effects chain.

The effects

ECF-42 filter

Add an ECF-42 Envelope Controlled Filter and set it to low-pass. Assign filter frequency to Combinator Control 1 and filter resonance to Combinator Control 2.

CF-101 chorus/flanger

Add a CF-101 Chorus/Flanger to widen and enrich the lead sound.

RV-7 reverb

Add an RV-7 Digital Reverb with a small room size and a mostly dry mix.

Creating a chord progression

The easiest way to start a chord progression is to use the circle of fifths.

You can move to adjacent chords around the inner or outer circle, or move between adjacent chords on the inner and outer rings.
