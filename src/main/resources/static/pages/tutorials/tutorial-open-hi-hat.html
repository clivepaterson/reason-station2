Creating an open hi-hat

How to create an open hi-hat using Subtractor.

A hi-hat can be created using only the Noise Oscillator. An open hi-hat uses the same technique as a closed hi-hat, but with a longer decay.

The Subtractor settings

  1. Create a Subtractor synthesizer and reset the device.
  2. Turn off Oscillators 1 and 2 by disabling Oscillator 2 and moving the mix fully toward Oscillator 2.
  3. Turn on the Noise Generator and set its level and decay to maximum.
  4. Set Filter 1 to high-pass at around 6 kHz to remove all low frequencies. This is slightly lower than the frequency used for a closed hi-hat.
  5. Set the Amp Envelope to no attack, a short decay that is longer than the closed hi-hat, and no sustain or release.

The effects

Distortion

Add some distortion to give the open hi-hat extra character.
